# 나머지 절 (5~7절) 코드와 설명

| 절 | 하는 일 | 필요한 런타임 |
|---|---|---|
| 5-1 | 가짜 모델로 영상 3개 → 데이터 읽기·저장이 되는지 확인 | **CPU로 가능** (무료) |
| 5-2 | 진짜 Molmo로 영상 5개 → 모델이 올라가고 점수가 나오는지 확인 | **GPU (A100)** |
| 5-3 | Molmo로 영상 20개 → 논문 수치와 비교 + 소요 시간 측정 | GPU (A100) |
| 5-4 | 5-3 결과를 표로 요약 | 아무거나 |
| 5-5 | (선택) 열화 3종을 5개씩 시험 | GPU (A100) |
| 6 | 본 실험: 원본 + 열화 9조건을 같은 영상 50개로 (한 명이 전부) | GPU, 오래 걸림 |
| 7 | 결과 표·그래프 만들기 (하락률, 신뢰구간) | 아무거나 |

**오늘 무료 코랩(CPU)에서는 5-1까지만** 하면 된다. 5-2부터는 Molmo(70억 파라미터 모델)를 돌려야 해서 A100 GPU가 필요하다.

공통으로 쓰는 옵션
- `--n`: 영상 몇 개를 돌릴지 (0이면 전체)
- `--seed`: 영상을 고르는 무작위 기준. 같은 값이면 매번 같은 영상이 뽑혀서 원본과 열화 결과를 짝지어 비교할 수 있다
- `--out`: 결과 CSV를 저장할 폴더 (Drive)
- `--mock`: 가짜 모델 사용 (GPU 없이 확인용)
- `--degrade`, `--level`: 열화 종류와 단계

## 6. 본 실험 (영상 50개 × 10조건, 한 명이 전부 실행)
원본 1 + 열화 3종 × 3단계를 같은 영상 50개로 차례로 돈다. 5-3에서 돌린 원본 20개는 가져와서 다시 돌리지 않는다.

- 예상 시간: 원래 추정 약 17시간. 시점 질의를 첫 "Yes"에서 멈추도록 바꿔서(예측은 공식 방식과 똑같음) 이보다 짧아질 것으로 예상한다.
- **브라우저 탭을 열어 둔 채로** 돌린다. 연결이 끊기면 1~4절을 다시 실행하고 이 셀을 다시 실행하면 끝난 조건·영상은 건너뛰고 이어서 돈다 (결과는 Drive에 있음).
- 결과는 조건마다 `RUN` 폴더에 CSV로 쌓인다. 진행 상황은 각 줄의 진행 막대로 본다.
- `LEVELS`는 논문 초안 v2 표 I의 잠정값이다.
```python
N = 50
SEED = 0
RUN = f'{OUT}/main_n{N}'
LEVELS = {'resize': [2, 4, 8], 'h264': [37, 42, 47], 'blur': [6, 11, 17]}  # 논문 초안 v2 표 I 잠정값

import os, shutil
os.makedirs(RUN, exist_ok=True)
# 5-3에서 돌린 원본 결과가 있으면 가져와서 이어서 돌림
if os.path.exists(f'{OUT}/molmo_clean.csv') and not os.path.exists(f'{RUN}/molmo_clean.csv'):
    shutil.copy(f'{OUT}/molmo_clean.csv', f'{RUN}/molmo_clean.csv')

!python pilot_when_where.py --n {N} --seed {SEED} --out {RUN}
for kind, levels in LEVELS.items():
    for lv in levels:
        !python pilot_when_where.py --n {N} --seed {SEED} --degrade {kind} --level {lv} --out {RUN}
```
